---
name: session-start
description: Use at the start of every Zigcraft session, before choosing or changing anything.
---

1. Do [CONTRIBUTING.md](../../../CONTRIBUTING.md) step 1: read STATUS, ROADMAP
   and the session log, fetch, and list open pull requests.
2. Choose one roadmap item that no open pull request covers. A broken `main`
   comes first.
3. Do CONTRIBUTING step 2: your own worktree from fresh `origin/main`, then
   `bash scripts/setup.sh` in it.
4. Write one or two sentences: the item, and the player action or game state
   that will show it is done (CONTRIBUTING step 3).

Done when you are in a fresh worktree on a new branch, setup has run, and the
done statement is written.
