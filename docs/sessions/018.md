# Session 018

Date: 2026-10-02
Branch: `feat/voxel-ambient-occlusion`

## Goal

Implement Milestone 26: Voxel Ambient Occlusion (per-vertex corner darkening in chunk shader).

## What was done

- **Shaders (`src/renderer/shader.zig`):**
  - Updated vertex layout: added `layout (location = 3) in float aAO;`.
  - Passed `FragAO` to fragment shader.
  - Multiplied fragment direct & ambient light by `ao_factor = 0.55 + 0.45 * FragAO`, giving realistic smooth shading into inner corners, caves, and block crevices without expensive ambient calculations.
- **Chunk Renderer (`src/chunk_renderer.zig`):**
  - Updated vertex attribute pointers: added attribute location 3 for `ao` (`1` float component).
- **Ambient Occlusion Sampling (`src/world/chunk_mesh.zig`):**
  - Added `ao: f32` to `Vertex` struct.
  - Implemented `vertexAO(side1, side2, corner)` helper according to voxel ambient occlusion standards:
    - If both side neighbors are solid: occluded (0.2).
    - Otherwise: $1.0 - (\text{solid\_count} \times 0.25)$.
  - In greedy quad generation: sampled corner and side neighbors along quad boundary offsets for each of the 4 emitted quad vertices.
  - Hardened `getBlockSafe` against out-of-bounds cross-chunk indexing.
- **Tests & Verification:**
  - Added unit test checking Vertex struct layout and standalone block full illumination (`ao >= 0.99`).
  - All 20 module unit tests pass (`zig build test`).
  - Live runtime verified: corners, crevices, waterbanks, and tree foliage now cast soft ambient voxel shadows at 145+ FPS.
