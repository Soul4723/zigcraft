# Session 359: Milestone 241 — Shears Tool: Sheep Wool Shearing, Cobweb & Foliage Cutting Pipeline

## Summary
Implemented Shears (`ItemType.shears = 240`), sheep shearing interaction, wool regrowth timers, cobweb/foliage accelerated cutting, and synthesized shears sound:
- **Item Definitions & Durabilities**:
  - `ItemType.shears = 240` (tool, max durability 238, stack 1).
  - Added `ItemType.isShears()` helper query.
  - Metallic iron palette `.{ 0.82, 0.82, 0.84, 0.95 }`.
- **Harvesting & Mining Multipliers**:
  - `TOOL_SHEARS = 240`.
  - Added `isShearableBlock(block)` covering leaves, cobwebs, weeping vines, twisting vines, and wool.
  - Multipliers: Cobwebs 15.0x (swiftly clears mineshaft obstructions), Leaves 10.0x, Wool & Vines 5.0x.
  - Updated `canHarvestBlock` to authorize shears harvesting.
- **Sheep Shearing & Wool Regrowth Cycle**:
  - Added `is_sheared: bool` and `regrow_timer: f32` to `Mob`.
  - Right-click on un-sheared sheep with shears drops 2 wool, consumes 1 tool durability, triggers sheep shorn state, and starts a 45-second wool regrowth timer.
  - Mob renderer dynamically adjusts sheep body mesh dimensions from 0.5x0.45x0.7 down to 0.42x0.38x0.62 and swaps texture tile to sheared skin.
  - Added `tryShearSheep` raycast query to `MobManager`.
- **Audio Synthesizer**:
  - Added `SoundType.shears_snip` with realistic dual metallic blade snip (high-frequency scrape sweep 2400Hz -> 1800Hz + edge noise + transient snap).
- **Crafting Recipes**:
  - Recipe 182: 2 Iron Ingots -> 1 Shears (supports diagonal or horizontal 2x2 grid patterns).
