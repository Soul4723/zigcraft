# Session 272: Dispenser Block Crafting & Autonomous Redstone Projectile Launch

Date: 2026-10-13

## Goal
Implement Milestone 154: Dispenser Block Crafting & Autonomous Redstone Projectile Launch. Add Dispenser (`BlockId.dispenser = 75`, `ItemType.dispenser = 104`), Recipe 69, block face nozzle textures, stone hardness, redstone rising-edge power detection (`isDispenserPowered`), and autonomous projectile launching (arrows, spectral arrows, fireworks rockets) with muzzle flame/smoke bursts.

## What was done

  - Properties: solid, hardness 3.5, wooden harvest tier, pickaxe multipliers (stone 3.0, iron 4.0, netherite 6.0), footstep stone.
  - Multi-tile textures: front nozzle face `(0, 5)`, cobblestone casing sides/top/bottom `(1, 3)`.

  - Added Recipe 69: 1 Bow / Crossbow + 1 Redstone Dust + 1..2 Cobblestone -> 1 Dispenser.
  - Added unit test covering properties, roundtrips, and crafting recipes.
- `src/world/redstone.zig`:
  - Added `isDispenserPowered(get, x, y, z)` checking adjacent wires, repeaters, torches, levers, and pressure plates.
  - Added unit test verifying adjacent redstone power detection.
- `src/main.zig`:
  - Added `DispenserState` tracking placed dispensers, redstone activation state, and loaded ammo count (9 rounds default).
  - Wired placement hook when putting down dispensers.
  - Implemented dispenser autonomous firing: on rising-edge redstone power, launches cycling projectiles (arrows, spectral arrows, firework rockets) out front nozzle at high speed with smoke/flame burst and firing audio. When empty, emits `.click_off`.
