# Session 022

Date: 2026-10-02
Branch: `feat/multiplayer`

## Goal

Implement Milestone 30: Client-server multiplayer networking, player position and block edit synchronization, remote humanoid player rendering, and CLI modes.

## What was done

- **Binary Packet Protocol (`src/net/protocol.zig`):**
  - Designed binary framing header: 2-byte magic (`0x5A43`), 1-byte message type enum, 2-byte payload length.
  - Defined serialization & deserialization for:
    - `join` / `welcome` (handshake with assigned player ID & spawn coordinates)
    - `position` (client to server) & `player_position` (server broadcast to peers)
    - `block_edit` (client to server) & `player_block_edit` (server broadcast to peers)
    - `player_leave` (peer disconnect notification)
    - `chat` / `player_chat` (text broadcast)
- **Non-blocking POSIX Sockets (`src/net/socket.zig`):**
  - Socket wrapper with `TCP_NODELAY`, `SO_REUSEADDR`, and non-blocking `O_NONBLOCK` support.
  - Cross-platform POSIX socket operations (`listen`, `connect`, `accept`, `send`, `recv`).
- **Dedicated Game Server (`src/net/server.zig`):**
  - Tracks up to 16 concurrent clients.
  - Broadcasts position updates and relays block edits to all connected peers.
  - Handles client disconnects and clean slot recycling.
- **Client Networking Integration (`src/net/client.zig`):**
  - Non-blocking client tick in main loop.
  - Buffering and packet sliding for partial and streamed packets.
  - Queues remote block edits for application to world chunk manager.
  - Animates remote player limb walk cycles.
- **Remote Player Humanoid Renderer (`src/net/player_renderer.zig`):**
  - Multi-box humanoid mesh generator: head, torso, left leg, right leg with sinusoidal walking animations.
  - Textured using existing atlas tiles (face, blue shirt, brown pants) matching game aesthetic.
  - Dynamic streaming to OpenGL VAO/VBO/EBO pipeline.
- **Game Loop & CLI Integration (`src/main.zig`):**
  - Added CLI flag `--server [--port <port>]` for headless dedicated server mode.
  - Added CLI flag `--connect <ip> [--port <port>]` for multiplayer client mode.
  - Position streaming at ~20Hz; block destruction/placement immediately transmitted over network.
  - Live peer count displayed on window title and debug HUD.
- **Build & Tests (`build.zig`, `src/net.zig`):**
  - Added standalone `src/net.zig` test target covering all networking submodules.
  - Added end-to-end loopback integration test simulating server and 2 concurrent clients exchanging positions and block updates.
  - 197/197 unit tests passing.
