# Session 022

Date: 2026-10-02
Branch: `feat/inventory-and-crafting`

## Goal

Implement Milestone 31: Crafting & Inventory GUI.
- Dedicated item/stack inventory data structure with item definitions and stack constraints.
- 2x2 player crafting grid with real-time recipe resolution (Wood -> Planks -> Sticks, Crafting Table, Wooden Pickaxe).
- In-game interactive GUI with HUD inventory rendering, 'E' toggleable inventory screen, cursor item pick/place, and audio chime.
- Drop block collection on block destruction into inventory, and consumption on placement.

## What was done

- **Inventory Subsystem (`src/inventory.zig`):**
  - Created `ItemType` enum supporting blocks (Stone, Dirt, Grass, Water, Wood Log, Leaves, Wood Planks, Crafting Table) and non-block craftables (Stick, Wooden Pickaxe).
  - Created `ItemStack` struct with stacking limits (64 for blocks/materials, 1 for tools) and decrement/clear operations.
  - Created `Inventory` struct managing 6 hotbar slots, 18 main inventory slots, a 2x2 crafting grid, and craft output slot.
  - Implemented real-time recipe matching and crafting output retrieval with material deduction.
  - Added unit tests for stacking, slot transfers, recipes, and boundaries.
- **Voxel Texture Atlas Additions (`src/world/block.zig`, `src/renderer/texture.zig`):**
  - Added Block IDs `.wood_planks` and `.crafting_table`.
  - Added atlas tile (2, 2) for wood planks and (3, 2) for crafting table grid top and borders.
- **Audio Craft Sound (`src/audio/synth.zig`):**
  - Synthesized dual-tone pop/chime (`.craft_item`) for item crafting audio feedback.
- **Interactive UI Overlay (`src/renderer/ui.zig`):**
  - Added bordered rectangle rendering primitives.
  - Expanded dynamic UI vertex buffer to 4096 vertices.
  - Implemented `drawHUD` displaying hotbar slots with item icons and count indicators.
  - Implemented `drawInventory` full-screen panel with 2x2 crafting grid, craft output slot, 18-slot main inventory, hotbar, and mouse cursor / held item.
- **Main Loop Integration (`src/main.zig`):**
  - Added 'E' key toggling cursor mode and inventory GUI.
  - Implemented GUI mouse clicking for slot swapping and crafting extraction.
  - Connected block destruction to item drop pickup in inventory.
  - Connected block placement to consuming items from hotbar stack.
