# Session 023

Date: 2026-10-03
Branch: `feat/voxel-texture-overhaul`

## Goal

Milestone 31 texture half: replace crude math-noise tiles with handcrafted-style
procedural pixel-art, add cobblestone + coal ore blocks with underground veins.

## What was done

- `src/renderer/texture.zig`: rewrote atlas around pure `tilePixel(tx,ty,x,y)`
  painter + `hash2` deterministic variation. New detail: bladed grass top, jagged
  grass-side fringe with shadow line, clod/pebble dirt, speckled cracked stone,
  ridged oak bark with knots, diamond-ring log tops, gapped leaf canopy, grained
  planks with staggered seams, framed crafting table with grooves/tool marks,
  cobblestone cells with mortar gaps, coal ore blobs on stone base. Tiles (2,3)
  and (3,3) reserved transparent. 3 new unit tests (opacity, determinism, ore
  cores, fringe rows).
- `src/world/block.zig`: added `.cobblestone` (tile 0,3) and `.coal_ore`
  (tile 1,3) with defs, face mapping, tests.
- `src/inventory.zig`: added `.cobblestone` / `.coal` items with
  toBlockId/fromBlockId, names, colors.
- `src/world/terrain.zig`: `stoneAt` vein placement (coal ~1/14 and
  cobble ~1/11 at y=1..3, cobble ~1/23 at y=4) replaces deep stone. Test checks
  vein counts in 64x64x3 volume and no veins at y=8.
- `src/main.zig`: footstep sounds for new stone types.
- Docs: STATUS.md + ROADMAP.md updated (milestone 31 texture half done).
