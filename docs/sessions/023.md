# Session 023

Date: 2026-10-03
Branch: `feat/multiplayer-networking`

## Goal

Implement Milestone 30: Multiplayer foundation.
- Cross-platform non-blocking UDP networking socket layer via C interop (`sys/socket.h`).
- Binary protocol serializer/deserializer (`handshake`, `handshake_ack`, `player_pos`, `block_edit`, `chat_message`, `disconnect`).
- Dedicated & embedded game server tracking client connections, timeouts, and state broadcasting.
- Client network loop polling incoming packets and transmitting 20Hz player transform sync.
- Block edit replication across clients with live re-meshing.
- Remote player avatar box meshing & rendering (`PlayerRenderer`).

## What was done

- **Protocol & Packet System (`src/net/protocol.zig`):**
  - Defined compact binary packet types: Handshake, HandshakeAck, PlayerPos (float32 coords + yaw/pitch), BlockEdit (int32 coords + block byte), ChatMessage, Disconnect.
  - Serialization and deserialization methods with bounds checking.
  - Unit tests for all packet roundtrips.
- **Socket Abstraction (`src/net/socket.zig`):**
  - Wrapper around POSIX UDP sockets with `O_NONBLOCK` and `SO_REUSEADDR`.
  - Non-blocking `sendTo` and `recvFrom` with `Endpoint` addressing.
  - Unit tests verifying non-blocking local UDP packet transfer.
- **Server Subsystem (`src/net/server.zig`):**
  - Host server managing up to 8 connected clients with heartbeat tracking and 5s timeout purging.
  - Handles handshakes and assigns unique client IDs.
  - Broadcasts position updates and block edits to all connected peers except originator.
  - Unit tests for handshake exchange and player tracking.
- **Client Subsystem (`src/net/client.zig`):**
  - Client state machine sending handshakes, polling packets, and storing remote player transform states.
  - Queues incoming remote block edits for main thread chunk re-meshing.
  - 20Hz rate-limited position updates.
  - Unit tests connecting client to local server and verifying state synchronization.
- **Remote Player Rendering (`src/player_renderer.zig`):**
  - Multi-box player avatar mesh generation (head, torso, legs) with textured atlas mapping.
  - Dynamic GPU buffer streaming and rendering using chunk shader pipeline with sun lighting.
- **Game Loop Integration (`src/main.zig`):**
  - Integrated CLI argument parsing (`--server` or `--connect <ip>`). Defaults to embedded host server + local client for seamless singleplayer/LAN multiplayer.
  - Main loop synchronizes local player position to network and consumes incoming block edits into `ChunkManager.editAndRemesh`.
  - Renders remote player avatars in the 3D world.
  - Debug HUD shows real-time network status (`net=online`).
