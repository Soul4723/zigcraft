# Session 244: Bastion Piglin Mob & Gold Bartering System

Date: 2026-10-13

## Goal
Implement Piglin mobs and gold bartering (Milestone 126), populating Bastion Remnants with sword-wielding piglin guards that trade rare Nether wares for gold nuggets.

## What was done
- `src/inventory.zig`:
  - Added `MobType.piglin = 5`.
  - `getMobMeatDrop`: Piglin kills drop `ItemType.gold_nugget`.
  - `getPiglinBarter`: 8-entry deterministic bartering table accepting gold nuggets and returning Nether wares (crying obsidian, obsidian, fire charge, nether quartz, soul sand, blackstone, magma cream, nether brick).
  - Unit test verifying drops and bartering rewards.
- `src/entity/mob.zig`:
  - Piglin mob definition: width 0.6, height 1.5, speed 2.6, 10 HP.
  - Added `barter_timer: f32` tracking barter pacification, decremented in `Mob.tick`.
  - Sound mapping: Piglin uses `.mob_oink`.
  - Unit test verifying piglin stats, audio mapping, and barter timer decay.
- `src/world/spawn_rules.zig`:
  - `isBastionSpawn`: identifies blackstone or gilded blackstone floors with clear headroom for piglin guard posts.
  - Unit tests verifying bastion spawn conditions.
- `src/entity/mob_manager.zig`:
  - `ensureSpawnPopulation`: bastion pass spawns piglins on blackstone rampart ruins.
  - `tick`: piglin hunts player unless pacified (`barter_timer > 0.0`).
  - `tryBarter`: raycasts piglin, consumes gold nugget, sets 20s pacification timer, and rewards barter wares.
  - `tryHitMobDmg`: clears pacification timer on hit so attacked piglins retaliate.
  - Unit test verifying piglin bartering, pacification timer, and combat aggro reset.
- `src/entity/mob_renderer.zig`:
  - Piglin 10-box mesh (torso, head, snout, 2 floppy ears, 2 arms, golden sword, 2 legs = 240 verts, 360 indices) textured with pig skin, face, and golden seam tiles.
  - Unit test verifying vertex and index counts.
- `src/main.zig`:
  - Combat loop: piglins deal 1.5x attack damage unless player holds gold or piglin is pacified.
  - Barter interaction: right-clicking piglin with gold nugget triggers barter, plays chime, spawns gold spark particles, flashes golden toast, and yields barter wares.
- Verification: clean build, 1393/1393 unit tests passing (+6 tests).
