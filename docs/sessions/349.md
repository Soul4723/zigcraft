# Session 349: Milestone 231 — Redstone Ore, Subterranean Mineral Veins & Dynamic Luminescent Activation

## Summary
Implemented Redstone Ore & Lit Redstone Ore (`BlockId.redstone_ore = 145`, `lit_redstone_ore = 146`, `ItemType.redstone_ore = 214`), subterranean mineral generation, dynamic luminescent activation, and mining drops:
- **Block & Item Definitions**:
  - `BlockId.redstone_ore = 145` (solid, opaque, non-flammable, hardness 3.0, wooden tool harvest tier, stone footsteps).
  - `BlockId.lit_redstone_ore = 146` (solid, opaque, emissive 0.55 glowing scarlet crystal radiance, hardness 3.0, stone footsteps).
  - Face texture coordinates: `(1, 7)` for unlit ore, `(2, 7)` for lit glowing ore.
  - `ItemType.redstone_ore = 214` (stack cap 64, palette `.{ 0.65, 0.25, 0.25, 0.95 }`, roundtrip block mapping).
- **Mining Drops**:
  - Mining either unlit or lit redstone ore yields 4 Redstone Dust (`getBlockDrops(.redstone_ore)` and `getBlockDrops(.lit_redstone_ore)`).
- **Procedural World Generation**:
  - `src/world/terrain.zig`: integrated procedural subterranean redstone ore veins into deep bedrock strata (`wy >= 1 and wy <= 3`) via `oreHash(wx, wy, wz, 0x4E0570) % 23 == 0`.
- **Dynamic Interaction & Redstone Logic**:
  - `src/world/redstone.zig`: implemented `updateRedstoneOreState` state transition helper for lighting and decay.
  - `src/main.zig`: linked right-click / F-key interaction on Redstone Ore to ignite it into glowing Lit Redstone Ore with audio feedback.
