# Session 293: Milestone 175 - Blast Furnace Block Crafting & High-Speed Ore Smelting Pipeline

## Summary
Implemented Blast Furnace block crafting and a high-speed metallurgical smelting pipeline (5.0s cook duration, 2x regular furnace speed) dedicated exclusively to ores and minerals (`IronOre`, `AncientDebris`, `Sand`).

## Changes
- **Block Definitions (`src/world/block.zig`)**:
  - Added `BlockId.blast_furnace = 95` (solid, opaque, stone footstep, hardness 3.5, wooden tool tier).
  - Textures: Smooth stone chimney top `(0, 0)`, smooth stone foundation bottom `(0, 0)`, reinforced iron blast smelting chamber flanks `(0, 5)`.
  - Added unit test `blast_furnace block properties and textures`.
- **Item & Crafting (`src/inventory.zig`)**:
  - Added `ItemType.blast_furnace = 131` with block mappings, name, HUD color `(0.30, 0.32, 0.34, 0.95)`, stack 64.
  - Implemented Recipe 94: 1 Furnace + 1 Iron Ingot (or Iron Ore) + 1 Stone (or Cobblestone/Sandstone) -> 1 Blast Furnace.
  - Added unit test `blast_furnace item roundtrip, properties, and Recipe 94`.
- **High-Speed Smelting Pipeline (`src/world/smelting.zig`)**:
  - Added `blast_furnace_time = 5.0` (2x standard furnace speed).
  - Added `isOreItem(input)` check filtering `IronOre`, `AncientDebris`, and `Sand`.
  - Added `tickBlastFurnaceJob` processing fuel and ore inputs to yields.
  - Added unit test `tickBlastFurnaceJob high-speed ore smelting`.
- **Component Cache (`src/world/component_cache.zig`)**:
  - Added `blast_furnace_cap = 16` and `findBlastFurnace` lookup helper with unit tests.
- **Main Engine Loop & Interaction (`src/main.zig`)**:
  - Allocated `blast_furnaces` job array and placement tracking on block placement.
  - Added world block tick simulation: ticks `tickBlastFurnaceJob`, spawns upward fiery combustion sparks via `particles.spawnBurnSparks`, drops smelted ingots/items into player inventory, and emits flame burst VFX.
  - Added right-click interaction for `.blast_furnace`: deposits coal fuel or ore items with placement click audio and fiery blast spark burst VFX.

## Verification

- Full binary compilation: clean build with zero errors/warnings (`zig build`).
