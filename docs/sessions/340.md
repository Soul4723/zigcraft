# Session 340: Milestone 222 — Cave Spider Mob Variant, Venomous Bites & Mineshaft Spawner Cages

## Summary

  - Added `MobType.cave_spider`.

  - Spawner pulse checks Overworld subterranean flooring (`wood_planks`, `cobblestone`, `stone`) and spawns Cave Spiders with `.mob_hiss` acoustics.
- **Combat & Status Hazards (`src/main.zig`)**:
  - Cave spider melee bites inflict damage and toxic poison status on the player (`player.applyPoison()`).
