## Goal

Implement Milestone 527: Vault & Ominous Vault Multi-Player Key Unlocking & Reset Tokens in Zigcraft (`src/world/vault_multiplayer_reset.zig`).

## What was done

- Implemented `src/world/vault_multiplayer_reset.zig` featuring:
  - **Standard vs Ominous Vault Variants**:
    - Standard Vault unlocked with Standard Trial Key (`trial_key`), dispenses standard rewards (Diamonds, Emeralds, Iron Ingots, Golden Apples, Breeze Rods, food items).
    - Ominous Vault unlocked with Ominous Trial Key (`ominous_trial_key`), dispenses exclusive ominous rewards (Heavy Core 2.2% chance, Flow/Bolt armor trims, Wind Burst enchanted books, Flow banner pattern).
  - **Per-Player Lock Tracking**:
    - Tracks up to 64 independent player IDs per vault.
    - Eligible players see an animated spinning loot showcase (`displayPreview` / `displayItemVisible`) and ambient particles.
    - Already unlocked players see a dark keyhole (`keyholeIsDark(player_id) == true`) and cannot insert trial keys.
  - **Vault Reset Token**:
    - Consuming 1 Vault Reset Token on an already unlocked vault clears that specific player's lock (`resetPlayerLock(player_id)`), returning `.reset` and allowing them to unlock the vault again.
    - Rejects reset attempts during active ejection cycles or for players who have not unlocked.
  - **Item Ejection Physics**:
    - Ejects 3 to 6 items upward with velocity $v_y \in [0.35, 0.55]$ m/s.
    - Randomized radial horizontal dispersion with full circular coverage ($2\pi$ radians).
    - Centered item launch positions at $(x+0.5, y+1.0, z+0.5)$.
  - **Comparator Output Scaling**:
    - Emits signal strength 15 for the nearest eligible player, 0 for already unlocked players, and 0 when no players are present.
    - Deterministic tie-breaking on equal distances.
  - **Integration & Unit Testing**:
    - Added 37 unit tests covering variant key matching, loot exclusivity, heavy core 2.2% roll boundaries, multi-player independent unlocks, reset token consumption, ejection physics, and comparator outputs.
    - Registered `src/world/vault_multiplayer_reset.zig` in `build.zig` and connected representative frame-loop queries in `src/main.zig`.
