# Session 411: Milestone 503 - Ghast Fireball Tennis

Date: 2026-10-29

## Goal
Implement Ghast aerial artillery, fireball deflection, Return to Sender damage,
and drops in an isolated world-domain module.

## What was done
- Added `src/world/ghast_fireball_tennis.zig` with 10 HP and a 4x4x4m body,
  fire/lava/fall immunity, bounded gravity-free flight, ambient/warn sound
  cues, 64m line-of-sight detection, and a 10-tick red-orange charge.
- Added straight 20m/s fireballs, power-1 explosion results with netherrack and
  cobblestone resistance rules, up to 12 direct damage, and deflection by fist,
  sword, axe, arrow, snowball, and fishing rod hook.
- Reflected hits deal 1000 reported damage, kill the Ghast, and identify the
  original sender for Return to Sender. Loot rolls cover 0–2 gunpowder,
  Looting bonuses, Ghast tear chance, and five XP.
- Registered the module as a standalone test target. Live rendering, audio
  playback, world mutation, achievement persistence, and inventory changes are
  still owned by existing systems.
