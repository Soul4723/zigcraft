# Session 014

Date: 2026-10-02
Branch: `feat/ui-crosshair-hotbar`

## Goal

Implement onscreen 2D UI overlay (Crosshair + Hotbar block selection - Milestones 22 & 23).

## What was done

- **UI Renderer (`src/renderer/ui.zig`):**
  - Dedicated 2D overlay shader (`layout (location = 0) in vec2 aPos; layout (location = 1) in vec4 aColor;`).
  - Dynamic VBO rendering in normalized device coordinates (NDC).
  - Alpha blending enabled (`GL_BLEND`, `GL_SRC_ALPHA`, `GL_ONE_MINUS_SRC_ALPHA`), depth testing disabled during UI pass.
  - Draws centered crosshair reticle corrected for window aspect ratio.
  - Draws 3-slot hotbar at the bottom of the screen with active slot highlighted in white.
- **Main Loop Integration (`src/main.zig`):**
  - Hotbar blocks: Slot 1: Stone, Slot 2: Dirt, Slot 3: Grass.
  - Number keys `1`, `2`, `3` update `selected_slot`.
  - Right-click block placement uses the currently selected block type (`hotbar_blocks[selected_slot]`) instead of hardcoded stone.
  - Window title and HUD logs report selected block name.
- **Build & Tests:**
  - Added `src/renderer/ui.zig` test target to `build.zig`.
  - All 20 module unit tests pass (`zig build test`).
  - Binary verified running cleanly at 140+ FPS with crosshair and active hotbar rendering.
