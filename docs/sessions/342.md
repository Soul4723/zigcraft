# Session 342: Milestone 224 — Minecart Functional Variants: Chest, Furnace, TNT & Hopper Minecarts

## Summary
Implemented the four functional Minecart vehicle variants:
- Minecart with Chest (`ItemType.chest_minecart = 201`)
- Minecart with Furnace (`ItemType.furnace_minecart = 202`)
- Minecart with TNT (`ItemType.tnt_minecart = 203`)
- Minecart with Hopper (`ItemType.hopper_minecart = 204`)

Added Recipes 144, 145, 146, 147 for crafting each vehicle, rail deployment mechanics, and TNT Minecart kinetic fuse arming upon placement onto rail tracks.

## Changes
- **Items & Crafting Recipes (`src/inventory.zig`)**:
  - Added `ItemType.chest_minecart`, `ItemType.furnace_minecart`, `ItemType.tnt_minecart`, `ItemType.hopper_minecart` (all stack size 1).
  - Recipe 144: Minecart + Chest -> Minecart with Chest.
  - Recipe 145: Minecart + Furnace (or blast furnace/smoker) -> Minecart with Furnace.
  - Recipe 146: Minecart + TNT -> Minecart with TNT.
  - Recipe 147: Minecart + Hopper -> Minecart with Hopper.
- **Track Interaction & Mechanics (`src/main.zig`)**:
  - Right-click rails with any minecart variant deploys the vehicle onto tracks.
  - Placing a TNT Minecart on tracks arms a rapid 1.2s concussive kinetic fuse with flame particles and acoustic ignition.
  - Boarding mechanics for passenger carts.
