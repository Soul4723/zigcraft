## Key Learnings
- Zig 0.16.0: major breaking release. Training data is wrong.
  See docs/learnings/zig-0.16-changes.md.
- GLEW fails on Wayland. Use GL_GLEXT_PROTOTYPES + glcorearb.h.
- u4 cannot hold 16. Use usize for loop counters.
- ArrayList: .empty replaces .init(), methods take allocator param.
- glBufferData expects isize not usize. Use @intCast.
- indexOfScalarPos returns ?usize not !usize. Use orelse not catch.
