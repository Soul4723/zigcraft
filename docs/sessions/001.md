## Key Discoveries

- **Zig 0.16.0 breaks everything.** `std.io` gone, build API changed, package manifest
  syntax changed. The learnings doc is critical — without it, every session will waste
  time rediscovering these.
- **GLEW doesn't work on Wayland.** Use `GL_GLEXT_PROTOTYPES` with `glcorearb.h` instead.
  This is documented in CONTRIBUTING.md and the research docs.
- **The sandbox can't install packages or download files.** System deps must be installed
  by the user before sessions start.
