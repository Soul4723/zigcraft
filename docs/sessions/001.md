## Key Learnings

- Zig 0.16.0 has major breaking changes from older versions:
  `std.io` → `std.Io`, different build API, new package manifest format
- The sandbox environment can't install system packages or download files.
  System dependencies (zig, glfw, vulkan-headers, etc.) must be installed
  by the user before a session starts.
