# Session 282: Armor Stand Crafting, Equipment Display & Pose Swapping

Date: 2026-10-13

## Goal
Implement Milestone 164: Armor Stand Crafting, Equipment Display & Pose Swapping. Add Armor Stand block (`BlockId.armor_stand = 85`), item (`ItemType.armor_stand = 119`, stack size 16), Recipe 83 (1 Stone + 2..3 Sticks -> 1 Armor Stand), component cache tracking (`armor_stand_cap = 32`, `findArmorStand`), 4-stage pose cycling (`default_standing`, `salute`, `pointing`, `guarding`), armor mounting/swapping (`head`, `chest`, `legs`, `feet`), item restitution on block destruction, and audio/particle feedback.

## What was done
- `src/world/block.zig`:

  - Properties: solid, transparent, wood footstep, flammable, hardness 1.0.
  - Multi-tile face textures: smooth stone pedestal bottom `(0, 0)`, polished oak framing sides/top `(2, 2)`.

- `src/world/component_cache.zig`:

- `src/inventory.zig`:
  - Added `ItemType.armor_stand = 119` with maxStackSize = 16.
  - Added `ItemType.isArmor()` helper classifying helmets, chestplates, leggings, and boots.
  - Added Recipe 83: 1 Stone / Cobblestone + 2..3 Sticks -> 1 Armor Stand.
  - Added unit test covering Armor Stand item conversions, stack size, properties, `isArmor`, and Recipe 83.
- `src/main.zig`:
  - Added `ArmorStandPose` enum (`default_standing`, `salute`, `pointing`, `guarding`).
  - Added `ArmorStandState` tracking coordinates, pose, and mounted equipment slots (`head`, `chest`, `legs`, `feet`).
  - Added placement hook for armor stand blocks.
  - Added destruction cleanup in block loop: restitutes mounted armor items into player inventory and emits visual particle hints.
  - Added right-click interaction:
    - Held armor piece (`isArmor()`): mounts onto corresponding armor stand slot (`.head`, `.chest`, `.legs`, `.feet`), swapping previous item back into inventory with wood step audio and debris particles.
    - Empty-handed: cycles through 4 poses with mechanical click audio.
    - Other held item: retrieves equipped armor items from the stand.
