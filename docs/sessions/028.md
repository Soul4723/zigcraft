# Session 028

Date: 2026-10-03
Branch: `feat/underground-caves-iron-ore`

## Goal

Resolve UV tile bleeding onto leaf blocks (sheep faces appearing on trees) and overhaul terrain/canopy generation for organic Minecraft-like landscape.

## Root Cause

1. Texture atlas layout: `leaves` at (3, 1), `sheep_face` at (1, 2).
2. Greedy meshing merged adjacent leaf quads into size (w, h). Vertex UVs calculated `u_max = u_min + tile_size * w` and `v_max = v_min + tile_size * h`.
3. When `h > 1`, `v_max` extended past row 1 into row 2, sampling tile (1, 2) (sheep face) onto leaf blocks.
4. Terrain used uniform fBm clamped to 11 in 16-high chunks with 3x3 flat slab tree canopies.

## What was done

- `src/world/chunk_mesh.zig`:
  - Enforced 1x1 block face rendering with clamped UV coordinates (`u_max = u_min + tile_size`, `v_max = v_min + tile_size`).
  - Completely eliminated multi-tile atlas bleeding onto foliage and terrain.
- `src/world/terrain.zig`:
  - Natural terrain shaping: added 2D continentalness macro noise (freq 0.02) and ridge cuts (freq 0.035) combined with 4-octave fBm.
  - Organic tree canopies: varied trunk height (3..4 blocks) with spherical/rounded leaf crowns (corner-culled radius 2 + cross-top crown).
- All 206 unit tests passing. Headless run verified at ~143fps.
