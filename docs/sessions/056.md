Date: 2026-10-06
Branch: `feat/lamp-light-radius`

## Goal

Lit redstone lamps spill warm light onto neighbors at night (radius ~6),
so lamps read as light sources instead of glowing faces only.

## What was done

- `src/renderer/shader.zig`: chunk vert passes `FragWorldPos` via new
  `u_chunk_origin`; frag adds `u_lamp_pos[8]/u_lamp_count/u_night` and warm
  `1/(1+0.35d^2)` spill scaled by night.
- `src/chunk_renderer.zig`: `LampLight` struct; draw takes chunk origin +
  lamp light, sets new uniforms. Helpers `setUniformFloat/Vec3Array`.
- `src/chunk_manager.zig`: draw takes lamp spots + night, builds LampLight.
- `src/main.zig`: gathers up to 8 lit lamps within 48 blocks, night from
  `1 - day_factor`.
- `src/entity/mob_renderer.zig`: zeroes new uniforms (shared shader).
- `src/world/redstone.zig`: `lampGlow()` + test.
