# Session 327: Milestone 209 — Drowned Mob Variant, Trident Weapon, Throwing Kinematics & Aquatic Combat Pipeline

## Summary
Implemented the aquatic Drowned mob variant (`MobType.drowned`), water-based procedural spawning (`isWaterSpawn`), 7-box waterlogged zombie mesh with equipped Trident, craftable and harvestable Trident weapon (`ItemType.trident = 171`, durability 250), Key G high-velocity throwing kinematics (28 m/s, 8 damage), and mob contact/melee combat pipeline.

## Changes
- **Spawning Rules & Mob Manager (`src/world/spawn_rules.zig`, `src/entity/mob_manager.zig`)**:
  - Added `isWaterSpawn(world, x, y, z)` checking water depth and submerged layers.
  - Added aquatic spawning pass to `MobManager.update` spawning turtles and night drowned in water pools.
- **Drowned Mob Stats & Geometry (`src/entity/mob.zig`, `src/entity/mob_renderer.zig`)**:
  - `Mob.init`: 15 HP, 0.6m width, 1.8m height, 1.8 m/s land walk speed / 2.4 m/s swim speed in water, sound `.mob_growl`.
  - 7-box waterlogged geometry: cyan/teal decaying flesh, drenched tunic, algae-stained pants, forward-reaching left arm, right arm holding a glowing cyan Trident weapon.
- **Trident Item & Crafting (`src/inventory.zig`)**:
  - Added `ItemType.trident = 171` (durability 250, stack 1, tool check true, cyan color).
  - Added `MobType.drowned` dropping `ItemType.rotten_flesh`.
  - Added `dropsDrownedTrident(wx, wy, wz)` for rare deterministic 1-in-6 trident drops on drowned defeat.
  - Added Recipe 127: 2 Iron Ingots + 1 Scute + 1 Stick -> 1 Trident.
  - Comprehensive unit test covering trident item properties, tool checks, recipe, and drops.
- **Projectile Ballistics & Throwing Kinematics (`src/world/projectile.zig`, `src/main.zig`)**:
  - Added `trident_speed = 28.0`, `trident_damage = 8`, `trident_life = 5.0`, and `tridentInitialVelocity`.
  - Key G throwing handler releases Trident with water splash particle trail and acoustics.
  - Block impact drops/recovers Trident back to inventory.
  - Mob impact deals 8 damage, bursts water splash particles, and returns Trident to inventory.
  - Drowned melee strike added to hostile attack loop dealing 3 bonus damage with splash audio.

## Verification
- Unit test suite: all 2533 tests pass cleanly across 87 test steps (`zig build test`).
- Binary compilation: builds cleanly without errors (`zig build`).
