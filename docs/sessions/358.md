# Session 358: Milestone 240 — Hoe Tools: Foliage Harvesting Speed Multiplier & Crafting Pipeline

## Summary
Implemented the four tiers of Hoes: Wooden, Iron, Diamond, and Netherite (`ItemType.wooden_hoe = 236`, `iron_hoe = 237`, `diamond_hoe = 238`, `netherite_hoe = 239`), foliage-class block category classification, accelerated harvesting speed multipliers, and crafting recipes:
- **Item Definitions & Durabilities**:
  - `ItemType.wooden_hoe = 236` (tool, max durability 25, stack 1).
  - `ItemType.iron_hoe = 237` (tool, max durability 120, stack 1).
  - `ItemType.diamond_hoe = 238` (tool, max durability 250, stack 1).
  - `ItemType.netherite_hoe = 239` (tool, max durability 350, stack 1).
  - Added `ItemType.isHoe()` helper query.
- **Harvesting & Mining Mechanics**:
  - `TOOL_WOODEN_HOE = 236`, `TOOL_IRON_HOE = 237`, `TOOL_DIAMOND_HOE = 238`, `TOOL_NETHERITE_HOE = 239`.
  - Added `isFoliageClass(block)` covering leaves, hay bales, nether wart, chorus plants, chorus flowers, shroomlight, sponges, and wet sponges.
  - Multipliers on foliage-class blocks: Wooden 3.0x, Iron 4.0x, Diamond 5.0x, Netherite 6.0x (faster than bare hand, swords, pickaxes, or shovels).
  - Updated `canHarvestBlock` to authorize hoe harvesting.
- **Crafting Recipes**:
  - Recipe 178: 1 Wood Planks + 1 Stick (horizontal) -> 1 Wooden Hoe.
  - Recipe 179: 1 Iron Ingot + 1 Stick (horizontal) -> 1 Iron Hoe.
  - Recipe 180: 1 Diamond + 1 Stick (horizontal) or 1 Iron Hoe + 1 Diamond -> 1 Diamond Hoe.
  - Recipe 181: 1 Netherite Ingot + 1 Diamond Hoe / Iron Hoe -> 1 Netherite Hoe.
