## Goal

Implement and merge Milestone 530: Ominous Bottle Consumption & Bad Omen / Trial Omen Transformation Matrix in Zigcraft (`src/world/ominous_bottle_matrix.zig`).

## What was done

- Implemented `src/world/ominous_bottle_matrix.zig` featuring:
  - **Ominous Bottle Tiers & Drinking Consumption**:
    - 5 Bottle Tiers: Tier I through Tier V (`OminousBottleTier.tier_1` to `.tier_5`).
    - Amplifier: `tier - 1` (Tier I -> 0, Tier II -> 1, Tier III -> 2, Tier IV -> 3, Tier V -> 4).
    - Drinking duration: 32 ticks (1.6 seconds) via `OminousBottleDrink`.
    - Inventory consumption: consumes 1 ominous bottle, yields 1 glass bottle (`ItemType.glass_bottle`), emits `SoundEffect.potion_drink`.
    - Bad Omen status effect application: 120,000 game ticks (100 minutes).
    - Stacking rules: higher or equal tier updates amplifier and resets duration to 120,000 ticks; lower tier does not downgrade amplifier or duration.
  - **Village Raid Omen Transmutation**:
    - Village proximity boundary: 64.0m Euclidean radius ($r \le 64.0$).
    - Transmutes Bad Omen into Raid Omen, preserving amplifier tier.
    - Initiates 30-second (600 game ticks) countdown timer.
    - Emits `SoundEffect.raid_horn`.
    - At tick 600 expiration, triggers Village Raid with difficulty and wave count scaled by amplifier (Easy: 3/4, Normal: 5/6, Hard: 7/8).
  - **Trial Spawner Trial Omen Transmutation**:
    - Trial Spawner proximity boundary: 14.0m Euclidean radius ($r \le 14.0$) from active Trial Spawners.
    - Transmutes Bad Omen into Trial Omen, preserving amplifier tier ($0..4$).
    - Sets duration formula: $\text{duration\_ticks} = 18,000 \times (\text{amplifier} + 1)$ (18,000, 36,000, 54,000, 72,000, 90,000 ticks).
    - Emits `SoundEffect.trial_omen_transmute` and ominous particle vortex.
    - Signals nearby active Trial Spawners to upgrade to Ominous Trial Spawners.
    - Trial Spawner takes precedence over Village if both boundaries match.
  - **Milk Bucket Cleansing**:
    - Drinking Milk Bucket (`ItemType.milk_bucket`) cleanses all omens (Bad Omen, Raid Omen, Trial Omen), cancels raid countdown, reverts state to neutral, and returns empty bucket.
  - **Unit Testing & Verification**:
    - 53 comprehensive unit tests covering all amplifier mappings, 32-tick drinking timing, inventory bottle consumption and glass bottle yields, Bad Omen duration and stacking rules, 64.0m village boundary detection and 600-tick raid countdown, raid wave scaling, 14.0m trial spawner boundary detection and $18,000 \times (\text{amp}+1)$ duration calculation, spawner upgrade signaling, trial chamber precedence, and milk cleansing across all omens.
    - Registered `src/world/ominous_bottle_matrix.zig` in `build.zig`.
