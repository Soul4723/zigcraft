# Session 053

Date: 2026-10-06
Branch: `fix/stateless-redstone-power`

## Goal

Remove session-only redstone fragility: tracking arrays in `src/main.zig`
(`plates/wires/repeaters/lamps/red_torches`) only filled on local placement,
so TNT/mining/streaming/persistence edits bypassed them; wire power read
session flags so tick order mattered; repeater timer reset on rediscovery.

## What was done

- `src/main.zig`: per-4th-frame world scan over loaded chunks re-registers
  plates/wires/repeaters/lamps/torches from block ids; power flags re-derived
  from world. Placement-time appends deleted (sync covers next frame).
- Wire tick rewritten: source-seeded BFS over wire graph from world block ids.
  Lights/unlights independent of tick order both ways. TNT ignition, door
  open/close, particles/sounds preserved.
- Repeater: 0.1s delay kept in session; sync no longer clobbers in-flight
  delay (only resets timer when flag already matches block state).
