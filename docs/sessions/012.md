# Session 012

Date: 2026-10-02
Branch: `feat/chunk-persistence`

## Goal

Implement Milestone 18: Chunk persistence (saving and loading chunks to/from disk).

## What was done

- **Chunk Persistence Module (`src/world/persistence.zig`):**
  - Binary file format per chunk: `c_{cx}_{cz}.bin`.
  - Header: `ChunkHeader` with 4-byte magic (`ZCHK`), `version` (1), `cx`, `cz`.
  - Payload: full chunk block array (4096 bytes).
  - Implemented `loadChunk` and `saveChunk` using POSIX libc calls (`fopen`, `fread`, `fwrite`, `mkdir`).
  - Added unit test verifying save/load round-trip and non-existent file handling.
- **ChunkManager Integration (`src/chunk_manager.zig`):**
  - Added `persistence: Persistence` field to `ChunkManager`.
  - In `syncToCenter`: tries `persistence.loadChunk(cx, cz, &chunk)` first before generating terrain via `terrain.generateChunk`.
  - Marked chunks with `modified: bool` flag when blocks are edited via `setBlockWorld` / `editAndRemesh`.
  - On purge or manager `deinit`, modified chunks are automatically saved to disk.
- **Build & Tests:**
  - Added `src/world/persistence.zig` test target to `build.zig`.
  - `main.zig` configures world save directory `"saves"`.
  - All 18 module tests pass. Verified live binary runs cleanly with chunk persistence enabled.
