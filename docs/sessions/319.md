# Session 319: Milestone 201 — Shulker Mob Variant, Shulker Shell & Shulker Box Storage Pipeline

## Summary
Implemented the Shulker mob entity variant (`MobType.shulker`), 3-box peeking/opening shell geometry, long-range homing Shulker Bullet projectile with Levitation status affliction, Shulker Shell drop (`ItemType.shulker_shell = 160`), Shulker Box portable container block and item (`BlockId.shulker_box = 115`, `ItemType.shulker_box = 161`), and Recipe 118 (1 Chest + 2 Shulker Shells -> 1 Shulker Box).

## Changes
- **Player Status System (`src/player.zig`)**:
  - Added `levitation_timer = 10.0` status effect and methods `applyLevitation()` / `isLevitating()`.
  - Added vertical physics integration: while levitating, player ascends smoothly at `levitation_lift_speed = 2.5 m/s` countering gravity.
  - Unit tests: verified levitation application, upward climb speed, and timer decay.
- **Mob Variant & Geometry (`src/entity/mob.zig`, `src/entity/mob_renderer.zig`, `src/inventory.zig`)**:
  - Added `MobType.shulker` (30 HP, 0.8m width, 0.8m height, stationary `walk_speed = 0.0`).
  - Render geometry: 3-box articulate shell with lower shell base, animated peeking inner head, and opening upper shell lid.
  - Mob meat drop: defeats drop `ItemType.shulker_shell`.
  - Unit tests: verified shulker mob initialization, stationary physics, and shell drops.
- **Shulker Bullet & Combat Mechanics (`src/main.zig`)**:
  - Added `ThrownKind.shulker_bullet` (damage 4, life 6.0s).
  - Shulker firing loop: fires a homing missile toward the player every 3.0s when within 20m.
  - Impact handling: deals 4 damage (shield blockable, reduced by armor), applies 10s Levitation effect to player, and emits portal particles.
- **Shulker Box Block & Item (`src/world/block.zig`, `src/inventory.zig`)**:
  - Added `BlockId.shulker_box = 115` (hardness 2.0, solid, transparent shell, wooden tool tier, stone footstep, purple shell textures).
  - Added `ItemType.shulker_box = 161` and `ItemType.shulker_shell = 160`.
  - Added Recipe 118: 1 Chest + 2 Shulker Shells -> 1 Shulker Box.
  - World interaction: right-click deposits and withdraws items identical to Chest containers; breaking drops the block and retains container items.
  - Unit tests: verified block properties, item roundtrips, crafting recipe, and block drops.

## Verification
- Unit test suite: 2516 passing tests across 87 steps (`zig build test`).
- Binary compilation: built cleanly without errors (`zig build`).
