# Session 352: Milestone 234 — Diamond Gemstone, Diamond Ore, Block of Diamond & Subterranean Crystal Veins

## Summary
Implemented the Diamond Gemstone, Diamond Ore, and Block of Diamond (`BlockId.diamond_ore = 150`, `diamond_block = 151`, `ItemType.diamond = 217`, `ItemType.diamond_ore = 218`, `ItemType.diamond_block = 219`), subterranean diamond vein generation, and packing recipes:
- **Block & Item Definitions**:
  - `BlockId.diamond_ore = 150` (solid, opaque, hardness 3.0, wooden tool harvest tier, stone footsteps, texture atlas `(4, 2)` stone matrix with radiant cyan-blue diamond crystals).
  - `BlockId.diamond_block = 151` (solid, opaque, hardness 5.0, wooden tool harvest tier, stone footsteps, texture atlas `(5, 7)` polished crystalline cyan diamond gemstone block).
  - `ItemType.diamond = 217` (gemstone item, stack cap 64, palette `.{ 0.35, 0.85, 0.95, 0.95 }`).
  - `ItemType.diamond_ore = 218` (block item, stack cap 64, palette `.{ 0.45, 0.70, 0.80, 0.95 }`, roundtrip block mapping).
  - `ItemType.diamond_block = 219` (block item, stack cap 64, palette `.{ 0.40, 0.90, 0.95, 0.95 }`, roundtrip block mapping).
- **Crafting & Packing Pipeline**:
  - Recipe 160: 4 Diamonds (2x2 filled) -> 1 Block of Diamond.
  - Recipe 161: 1 Block of Diamond -> 4 Diamonds.
- **Drops & World Generation**:
  - Mining Diamond Ore drops 1 Diamond gemstone (`getBlockDrops(.diamond_ore)`).
  - Mining Block of Diamond drops itself (`getBlockDrops(.diamond_block)`).
  - Rare subterranean diamond vein distribution in `TerrainGenerator.stoneAt` for deep bedrock strata (`wy` 1..3) via `oreHash(wx, wy, wz, 0xD1A4) % 37 == 0`.
