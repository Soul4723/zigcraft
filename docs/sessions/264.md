# Session 264: Bow Weapon Crafting & Charged Pullback Ranged Combat

Date: 2026-10-13

## Goal
Implement Bow Weapon Crafting & Charged Pullback Ranged Combat (Milestone 146), adding Recipes 63 & 64, synthesized bow release audio, pullback charge mechanics with HUD progress bar, variable speed and damage scaling, arrow/spectral arrow ammo consumption, and tool wear degradation.

## What was done
- `src/audio/synth.zig`:
  - Added `.bow_shoot` sound type with ~200ms synthesized string release twang and snap click.
  - Added unit test verifying `.bow_shoot` non-zero audio output.
- `src/inventory.zig`:
  - Added `ItemType.arrow = 97` (maxStack 64, not tool, slate grey color).
  - Added `ItemType.bow = 98` (maxStack 1, maxDurability 384, tool, wood color).
  - Added Recipe 63: 1 Stick + 1 Iron Ingot / Nether Quartz -> 4 Arrows.
  - Added Recipe 64: 2 Sticks + 1 Wool / Twisting Vines / Weeping Vines -> 1 Bow.
  - Added `consumeItem(item)` and `consumeArrow()` helpers (prefers spectral arrow, falls back to regular arrow).
  - Added unit tests verifying item properties, recipes 63 and 64, and arrow consumption priority.
- `src/world/projectile.zig`:
  - Added `bow_draw_time` (1.0s), `bow_min_speed` (12.0), `bow_max_speed` (32.0), `bow_durability` (384).
  - Added `bowArrowSpeed(charge)` and `bowArrowDamage(charge)` scaling functions (12..32 m/s, 1..6 damage).
  - Added `bowInitialVelocity(dir_x, dir_y, dir_z, speed)` helper.
  - Added unit tests for speed and damage scaling.
- `src/main.zig`:
  - Added `.arrow` to `ThrownKind` projectile enum.
  - Added `damage: u8 = 1` field to `Thrown` struct.
  - Added `bow_charge: f32` state tracking held right-mouse drawing.
  - Connected `bow_charge` to HUD progress bar above crosshair for visual draw feedback.
  - Bound release of charged bow to consume an arrow from inventory, fire arrow/spectral arrow with scaled speed and damage, play `bow_shoot` audio, spawn sparks on critical shot (charge >= 0.95), and degrade bow durability.
  - Extended G-key throwing logic to support throwing regular arrows.
  - Connected regular arrow hits on target blocks and mobs.
