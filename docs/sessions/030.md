# Session 030

Date: 2026-10-03
Branch: `feat/expanded-atlas-glass-sandstone`

## Goal

Expand procedural texture atlas capacity to 8x8 (64 tiles) to support rich building materials: Glass, Sandstone (top/side/bottom multi-face), and Red Bricks, with corresponding crafting recipes and transparency rules.

## What was done

- `src/renderer/texture.zig`:
  - Upgraded atlas dimensions from 4x4 (64x64px) to 8x8 (128x128px), `TILE_UV_SIZE = 1/8 = 0.125`.
  - Added new pixel art textures:
    - **Glass (0, 4)**: Translucent cyan-tinted core (`alpha = 30`), frosted borders (`alpha = 240`), and dual diagonal specular glint streaks (`alpha = 180..210`).
    - **Sandstone Top (1, 4)**: Smooth warm sand compaction texture.
    - **Sandstone Side (2, 4)**: Stratified geological sediment bands with a decorative carved hieroglyphic/relief border trim on bottom layer.
    - **Sandstone Bottom (3, 4)**: Rough cracked rocky underside.
    - **Red Brick (4, 4)**: Traditional running-bond terracotta clay bricks with mortar seams.
  - Tests updated for 8x8 UV coordinate mapping and tile opacity checks.
- `src/world/chunk_mesh.zig`:
  - Updated `tile_size` from `0.25` to `0.125` for single block quad UV coordinate calculation.
- `src/world/block.zig`:
  - Added `BlockId.glass = 13`, `sandstone = 14`, `brick = 15`.
  - Marked `.glass` as transparent (`is_transparent() = true`) to enable viewing through windows.
  - Multi-face texturing for Sandstone: top (1, 4), side (2, 4), bottom (3, 4).
  - Hardness & tool requirements: sandstone (1.8s) and brick (2.0s) mine faster with wooden pickaxe; glass breaks quickly (0.3s).
- `src/inventory.zig`:
  - Added `ItemType.glass`, `sandstone`, `brick` with GUI item colors and block mappings.
  - Added 3 crafting recipes:
    - 4 Sand (2x2) -> 1 Sandstone
    - 4 Cobblestone (2x2) -> 4 Bricks
    - 1 Sand + 1 Coal (vertical) -> 2 Glass (smelting simulation in 2x2 grid)
  - Unit tests covering all 3 recipes.
- `src/main.zig`:
  - Added footstep sound mappings for new blocks.
