# Session 295: Milestone 177 - Lantern Block Crafting, Hanging Physics & Warm Ambient Illumination

## Summary
Implemented the Lantern luminescent block (`BlockId.lantern = 97`, `ItemType.lantern = 133`, Recipe 96), resting/hanging support physics (`canSupportLantern`), warm 0.95 emissive radiance, and transparent casing textures.

## Changes
- **Block Definitions (`src/world/block.zig`)**:

- **Item & Crafting (`src/inventory.zig`)**:
  - Added `ItemType.lantern = 133` with block conversions, name, HUD color `(0.95, 0.75, 0.35, 0.95)`, stack 64.

  - Added unit test `lantern item roundtrip, properties, and Recipe 96`.
- **Placement Physics (`src/main.zig`)**:
  - Enforced placement condition: placement only succeeds if `canSupportLantern` returns true (resting on a solid floor or suspended from a solid ceiling).
