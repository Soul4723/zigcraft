# Session 248: Hay Bale Block & Campfire Smoke Signals

Date: 2026-10-13

## Goal
Implement Hay Bale Block and Campfire Smoke Signals (Milestone 130), introducing hay bales with fall impact cushioning (80% fall damage reduction) and campfire smoke particle emission with hay bale signal smoke elevation.

## What was done
- `src/world/block.zig`:
  - Added `BlockId.hay_bale = 70`.
  - Properties: solid, non-transparent, flammable, hardness 0.5, footstep grass, hand harvest tier.
  - Textures: side faces use golden dried wheat stalks and twine `(0, 3)`; top/bottom cap uses bound straw end cross-section `(1, 4)`.
  - Unit test verifying block definition, solidness, flammability, footstep, and textures.
- `src/inventory.zig`:
  - Added `ItemType.hay_bale = 85`.
  - Item roundtrip, color `(0.85, 0.75, 0.25)`, and single drop on break.
  - Recipe 51: 2 Wood Planks + 2 Saplings/Leaves (or 4 Saplings) -> 1 Hay Bale.
  - Recipe 50: Target block recipe expanded to allow hay bale or wood planks + redstone.
  - Unit test verifying item roundtrip, drops, and Recipe 51.
- `src/renderer/particles.zig`:
  - Added `spawnCampfireSmoke` method supporting standard campfire smoke and high-altitude signal smoke.
  - Signal fire smoke particles feature extended lifetime (3.5s vs 1.4s), higher thermal lift velocity (4.2 vs 1.6 m/s), expanding volume, and soul-smoke tinting for soul campfires.
  - Unit tests verifying standard and signal smoke properties.
- `src/player.zig`:
  - Extended player physics with `tickPhysicsFull` and surface-aware fall damage.
  - Landing on hay bales reduces fall damage by 80% (`hay_cushion_multiplier = 0.20`).
  - Unit tests verifying cushioning math and player physics landing on hay bales.
- `src/main.zig`:
  - Registered campfire tracker array for placed and ignited campfires.
  - Main loop emits campfire smoke particles within 32m radius; detects if block below is hay bale to elevate into signal smoke.
  - Connected `pickHay` floor callback to player physics for fall damage reduction.
- Verification: clean build, all unit tests passing.
