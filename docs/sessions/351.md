# Session 351: Milestone 233 — Gold Ore, Block of Gold, Subterranean Auric Veins & Packing Pipeline

## Summary
Implemented Gold Ore & Block of Gold (`BlockId.gold_ore = 148`, `gold_block = 149`, `ItemType.gold_ore = 215`, `ItemType.gold_block = 216`), subterranean auric mineral generation, and bidirectional gold packing:
- **Block & Item Definitions**:
  - `BlockId.gold_ore = 148` (solid, opaque, hardness 3.0, wooden tool harvest tier, stone footsteps, texture atlas `(3, 2)` stone matrix with rich golden nuggets).
  - `BlockId.gold_block = 149` (solid, opaque, hardness 3.0, wooden tool harvest tier, stone footsteps, texture atlas `(4, 7)` polished gilded auric gold ingot block).
  - `ItemType.gold_ore = 215` (stack cap 64, palette `.{ 0.75, 0.70, 0.35, 0.95 }`, roundtrip block mapping).
  - `ItemType.gold_block = 216` (stack cap 64, palette `.{ 0.95, 0.85, 0.20, 0.95 }`, roundtrip block mapping).
- **Crafting & Packing Pipeline**:
  - Recipe 158: 4 Gold Nuggets (2x2 filled) -> 1 Block of Gold.
  - Recipe 159: 1 Block of Gold -> 4 Gold Nuggets.
- **Drops & World Generation**:
  - Mining Gold Ore drops 2 Gold Nuggets (`getBlockDrops(.gold_ore)`).
  - Mining Block of Gold drops itself (`getBlockDrops(.gold_block)`).
  - Subterranean auric vein distribution in `TerrainGenerator.stoneAt` for deep strata (`wy` 1..3) via `oreHash(wx, wy, wz, 0x601D) % 29 == 0`.
