# Session 278: Daylight Detector Block Crafting & Solar Inversion Redstone Sensor

Date: 2026-10-13

## Goal
Implement Milestone 160: Daylight Detector Block Crafting & Solar Inversion Redstone Sensor. Add Daylight Detector (`BlockId.daylight_detector = 80`, `ItemType.daylight_detector = 112`) and Inverted Daylight Detector (`BlockId.daylight_detector_inverted = 81`), Recipe 76 (1 Nether Quartz + 1 Glass + 1 Wood Planks -> 1 Daylight Detector), solar photovoltaic cell top texture `(3, 7)` / inverted night cyan cell top `(7, 1)` / oak wood sides `(2, 2)`, 0.2 hardness, wooden footstep, solar sun angle signal strength calculation (0..15 strength), wire network driving, and right-click day/night mode toggle.

## What was done
- `src/world/block.zig`:
  - Added `BlockId.daylight_detector = 80` and `BlockId.daylight_detector_inverted = 81`.
  - Properties: solid, opaque, hardness 0.2, wood footstep.
  - Multi-tile face textures: day top `(3, 7)`, inverted night top `(7, 1)`, oak wood sides/bottom `(2, 2)`.
  - Added unit test covering block definitions, hardness, footstep type, and face textures.
- `src/inventory.zig`:
  - Added `ItemType.daylight_detector = 112` with block roundtrip, name ("Daylight Detector"), and golden-solar color.
  - Added Recipe 76: 1 Nether Quartz + 1 Glass + 1 Wood Planks -> 1 Daylight Detector.
  - Added unit test covering ItemType roundtrips, block conversions, properties, and Recipe 76.
- `src/world/redstone.zig`:
  - Implemented `daylightSignalStrength(sun_y: f32, inverted: bool) u4`:
    - Normal mode: scales linearly from 0 at horizon (`sun_y <= 0`) to 15 at high noon (`sun_y >= 0.8`).
    - Inverted mode: scales linearly from 0 at horizon (`sun_y >= 0`) to 15 at midnight (`sun_y <= -0.8`).
  - Added unit test verifying day and inverted night signal strength scaling.
- `src/main.zig`:
  - Integrated daylight detector signal strength into redstone wire relaxation loop (`redstone_mod.daylightSignalStrength(@sin(world_time), inverted)`), driving adjacent redstone wires based on celestial sun height (inhibited in Nether).
  - Wired right-click interaction: toggles placed daylight detectors between normal solar mode and inverted night sensor mode with click audio and particles.
