# Session 280: Jukebox Block Crafting & Music Discs Vinyl Playback

Date: 2026-10-13

## Goal
Implement Milestone 162: Jukebox Block Crafting & Music Discs Vinyl Playback. Add Jukebox block (`BlockId.jukebox = 83`, `ItemType.jukebox = 114`), Music Discs (`ItemType.music_disc_13 = 115`, `ItemType.music_disc_cat = 116`), Recipes 78, 79, 80, Fortress loot integration, synthesized vinyl record playback voices (`.record_13`, `.record_cat`), jukebox state tracking (`JukeboxState`), and interaction mechanics (disc insertion, playback timer with note shimmer particles, disc ejection).

## What was done
- `src/world/block.zig`:
  - Added `BlockId.jukebox = 83`.
  - Configured block properties: solid, opaque, hardness 2.0, wood footstep, flammable.
  - Added face texture mapping: phonograph spindle aperture `(6, 3)` top, oak bottom `(2, 2)`, acoustic chest sides `(4, 3)`.
  - Added unit test verifying jukebox properties and textures.
- `src/inventory.zig`:
  - Added `ItemType.jukebox = 114`, `ItemType.music_disc_13 = 115`, `ItemType.music_disc_cat = 116`.
  - Discs configured as non-stackable (`maxStackSize = 1`).
  - Added Recipe 78: 1 Gold Nugget / Nether Quartz / Nether Star + 2..3 Wood Planks -> 1 Jukebox.
  - Added Recipe 79: 1 Gold Nugget + 1 Coal -> 1 Music Disc (13).
  - Added Recipe 80: 1 Warped Fungus + 1 Coal -> 1 Music Disc (cat).
  - Fortress chest loot integration: 25% chance roll in slot 3 for music discs.
  - Added unit tests for disc items and Recipes 78, 79, 80.
- `src/audio/synth.zig`:
  - Added `SoundType.record_13` (A-minor sequence with vinyl surface crackle) and `SoundType.record_cat` (C-major arpeggio with vinyl crackle).
  - Added pseudo-random hash generator `hash2` for vinyl crackle pops.
  - Added audio test asserting non-zero synthesized waveforms for record tracks.
- `src/world/component_cache.zig`:
  - Added `jukebox_cap = 32` and `findJukebox` coordinate lookup helper with unit test.
- `src/main.zig`:
  - Added `JukeboxState` tracking `{ x, y, z, playing_disc, play_timer }`.
  - Added placement hook for jukebox blocks.
  - Added jukebox playback tick loop: decrements `play_timer`, spawns note shimmer particle effect above the spindle, and clears active disc on timer expiration.
  - Added right-click interaction: ejects current disc into player inventory if playing; inserts and starts playback if player holds music disc 13 or cat.

## Verification
- `zig build`: compiled cleanly.
- `zig build test`: all 1642 tests passed across 86 test steps.
