# Session 271: Crossbow Piercing Bolt Ballistics & Multi-Entity Penetration

Date: 2026-10-13

## Goal
Implement Milestone 153: Crossbow Piercing Bolt Ballistics & Multi-Entity Penetration. Allow crossbow bolts (regular and spectral arrows) to carry penetration charges (`pierce = 2`), passing through hit mobs without immediate projectile destruction and continuing along flight paths to pierce through line-of-fire targets behind.

## What was done
- `src/world/projectile.zig`:
  - Added `crossbow_pierce_count = 2`.
  - Added `decrementPierce(remaining_pierce)` helper returning `next_pierce` and `dead` status.
  - Added unit test checking 3-stage penetration lifecycle.
- `src/main.zig`:
  - Added `pierce: u8 = 0` and `last_hit_mob: ?usize = null` to `Thrown` projectile state.
  - Initialized crossbow bolt projectiles with `pierce = 2` (firework rockets retain `pierce = 0`).
  - Updated mob hit detection to exclude `last_hit_mob` from immediately re-colliding on subsequent tick.
  - On mob collision, piercing projectiles decrement pierce charges, burst sparks at exit wounds, retain trajectory velocity, and continue flying until pierce reaches 0.
