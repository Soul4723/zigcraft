# Session 294: Milestone 176 - Stonecutter Block Crafting & Masonry Shaping Pipeline

## Summary
Implemented the Stonecutter crafting table block (`BlockId.stonecutter = 96`, `ItemType.stonecutter = 132`), synthesized high-speed diamond rotary saw acoustic audio (`.stonecutter_saw`), Recipe 95, and right-click precision stone masonry shaping mechanics.

## Changes
- **Audio Synthesizer (`src/audio/synth.zig`)**:
  - Added `SoundType.stonecutter_saw`.
  - Implemented synthesized acoustic voice: circular diamond rotary saw whir (880Hz whining tone + 1760Hz overtone) + harsh stone friction grit noise with ~250ms envelope.
  - Updated audio test coverage for new sound voice.
- **Block Definitions (`src/world/block.zig`)**:
  - Added `BlockId.stonecutter = 96` (solid, transparent table profile, hardness 3.5, wooden tool tier, stone footstep).
  - Textures: Circular iron rotary saw blade top `(1, 1)`, smooth stone base bottom `(0, 0)`, chiselled stone mason frame sides `(1, 3)`.
  - Added unit test `stonecutter block properties and textures`.
- **Item & Crafting (`src/inventory.zig`)**:
  - Added `ItemType.stonecutter = 132` with block mappings, name, HUD color `(0.50, 0.50, 0.52, 0.95)`, stack 64.
  - Implemented Recipe 95: 1 Iron Ingot + 1..3 Stone (or Cobblestone/Sandstone) -> 1 Stonecutter.
  - Added unit test `stonecutter item roundtrip, properties, and Recipe 95`.
- **Component Cache (`src/world/component_cache.zig`)**:
  - Added `stonecutter_cap = 32` and `findStonecutter` lookup helper with unit test.
- **Engine Loop & Interaction (`src/main.zig`)**:
  - Allocated `stonecutters` array and tracked placement on block place.
  - Added right-click interaction for `.stonecutter`:
    - Stone input: precision shapes 1 Stone -> 1 Brick with circular saw audio & stone debris particles.
    - Cobblestone input: precision shapes 1 Cobblestone -> 1 Stone.
    - Pickaxe input: trues pickaxe chisel head (`tool_wear.uses = 0`) on rotary guide with sparks/debris.
    - Idle tap: plays rotary saw acoustic.
