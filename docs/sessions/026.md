## Goal

Milestone 35: Particle Effects. 3D block-break & placement debris particles.

## What was done

- `src/renderer/particles.zig` (new): `ParticleSystem` holding up to 256
  particles. Tiny 3D voxel cubes (36 vertices per particle) rendered via
  dynamic VBO with color shader (`vert_src` / `frag_src`), takes raw MVP
  pointer (`[*c]const f32`) for cross-dir import rule.
  `spawnBlockDebris(bx,by,bz, color, count)` adds burst with velocity jitter
  and randomized lifetime (0.6..1.0s). `tick(dt)` applies 18 m/s² gravity and
  swap-removes expired particles. 2 unit tests (spawn/gravity/expiration, capacity clamp).
- `src/main.zig`:
  - 16 debris particles spawned with block color on destruction.
  - 8 debris particles spawned on placement.
  - Per-frame `particles.tick(dt)` and `particles.draw(mvp.ptr())`.
- `build.zig`: standalone test target for `src/renderer/particles.zig`.
