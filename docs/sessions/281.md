# Session 281: Lead Item Crafting, Mob Leashing & Hitching Post Mechanics

Date: 2026-10-13

## Goal
Implement Milestone 163: Lead Item Crafting, Mob Leashing & Hitching Post Mechanics. Add Oak Fence (`BlockId.oak_fence = 84`, `ItemType.oak_fence = 117`), Lead (`ItemType.lead = 118`), Recipes 81 & 82, mob tethering states (`leashed_to_player`, `fence_post`), leash tension physics (`applyLeashTension`), hitching/unhitching fence posts, and leash snapping mechanics.

## What was done
- `src/world/block.zig`:
  - Added `BlockId.oak_fence = 84`.
  - Properties: solid, transparent, wood footstep, flammable, hardness 2.0.
  - Added `BlockId.is_fence()` helper recognizing both `.nether_brick_fence` and `.oak_fence`.
  - Face texture mapped to oak planks tile `(2, 2)`.
  - Added unit test covering oak fence properties, textures, and classification.
- `src/inventory.zig`:
  - Added `ItemType.oak_fence = 117` and `ItemType.lead = 118` (stack sizes 64).
  - Added Recipe 81: 2 Wood Planks vertically + 1 Stick (or 2 Planks + 2 Sticks) -> 2 Oak Fences.
  - Added Recipe 82: 1 Wool / Weeping Vines / Twisting Vines + 1 Stick -> 1 Lead.
  - Added unit test verifying ItemType conversions, properties, and Recipes 81 and 82.
- `src/entity/mob.zig`:
  - Added `leashed_to_player: bool` and `fence_post: ?struct { x: i32, y: i32, z: i32 }` to `Mob`.
  - Implemented `isLeashed()` helper.
  - Implemented `applyLeashTension(&pos, &vel, anchor_pos, dt)`: applies elastic spring force when dist > 3.0m, returns true (snaps lead) if dist > 10.0m.
  - Added unit test covering slack, taut, and snapped leash distance behavior.
- `src/entity/mob_manager.zig`:
  - Implemented `tryInteractLeash(origin, dir, max_dist, has_lead)`: attaches lead or unleashes leashed mob.
  - Implemented `tryHitchToFence(fence_x, fence_y, fence_z)`: hitches all player-leashed mobs to fence post.
  - Implemented `unhitchFence(fence_x, fence_y, fence_z)`: releases hitched mobs and returns lead items.
  - Added unit test covering leashing, hitching, and unhitching.
- `src/main.zig`:
  - In mob update loop: simulates tension physics toward player or fence post, drops lead item on excessive distance (>10m) snap, and spawns fiber string particle trail.
  - In player mob interaction: right-clicking mob with lead attaches leash, or retrieves lead if already leashed.
  - In player block interaction: right-clicking any fence block hitches player-leashed mobs as a hitching post or unhitches existing tied mobs.
