## Goal

Implement Milestone 29: Simple wandering voxel entity with AABB physics and rendering. Also fix missing `getBlockWorld` method on `ChunkManager`.

## What was done

- **ChunkManager Fix (`src/chunk_manager.zig`):**
  - Implemented `getBlockWorld(x, y, z)` world-space voxel query.
  - Refactored `isSolidWorld` to use `getBlockWorld(x, y, z).is_solid()`.
  - Added unit test verifying out-of-bounds, loaded, and empty block queries.
- **Procedural Mob Atlas Textures (`src/renderer/texture.zig`):**
  - Added Tile (0, 2): Off-white wool fleece texture.
  - Added Tile (1, 2): Sheep face with eyes, pupils, and muzzle skin.
- **Mob Physics & AI (`src/entity/mob.zig`):**
  - Defined `Mob` struct with position, velocity, orientation (`yaw`), AABB dimensions, and animation timers.
  - Implemented wandering AI with randomized idle and walk states.
  - Implemented 1-block obstacle auto-step/hop navigation and gravity physics.
- **Mob Segmented Renderer (`src/entity/mob_renderer.zig`):**
  - Generated segmented multi-box geometry: body, head, and 4 animated legs with sinusoidal walk cycles.
  - World-space rotation and vertex normal orientation matching voxel lighting.
  - Dynamic buffer streaming to OpenGL VAO/VBO/EBO pipeline.
- **Mob Herd Manager & Game Loop Integration (`src/entity/mob_manager.zig`, `src/main.zig`):**
  - Dynamic mob population maintenance (`ensureSpawnPopulation`) placing sheep on solid ground near spawn.
  - Real-time tick & draw in main game loop.
  - Debug HUD displays active mob count (`mobs: 6`).
